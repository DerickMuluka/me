Library Management System

A Java desktop application for managing library operations — book catalog, members, borrowing, and returns.

Overview

The Library Management System is a Java desktop application designed for small and medium libraries. It handles the complete workflow — from cataloging books to tracking borrowings and returns.

Built with Java Swing for the interface and JDBC for database connectivity, it provides a functional, clean experience for librarians and staff.

Key Features

  • Book catalog management (add, edit, delete, search)
  • Member registration with student/staff roles
  • Borrow and return processing with due dates
  • Overdue alerts and fine calculation
  • Availability status tracking
  • Basic reporting for library statistics

Technical Details

The application is built in Java using Swing for the GUI and JDBC for database operations. It follows OOP principles with separate classes for Book, User, and LibrarySystem.

MySQL stores books, members, and loan records. Exception handling is implemented throughout to manage scenarios like borrowing unavailable books or invalid credentials.

Tech Stack
