House Rental System

A property listing and management platform that connects landlords with tenants and simplifies the rental process.

Overview

The House Rental System replaces scattered property listings with a single platform where landlords list properties and tenants search, filter, and apply.

It includes an admin dashboard for managing listings, tenant applications, and rental agreements — all in one place.

Key Features

  • Property listings with images and details
  • Search and filtering by location, price, and type
  • Tenant application workflow
  • Landlord dashboard for managing properties
  • Admin panel for platform oversight

Technical Details

Built with HTML, CSS, PHP, JavaScript, and MySQL. The database stores properties, landlords, tenants, and applications with proper relationships.

Image uploads are handled securely through PHP with validation, and JavaScript provides client-side form validation and interactive filters.

Tech Stack

HTML CSS PHP JavaScript MySQL
