Campus Network Design

A comprehensive campus network infrastructure design covering topology, security, VLANs, and redundancy.

Overview

This project involved designing a complete network infrastructure for a university campus — from physical topology to IP addressing, VLAN segmentation, and security policies.

The design was simulated in Cisco Packet Tracer and validated against real-world constraints like bandwidth, budget, and scalability.

Key Components

  • Hierarchical topology (core, distribution, access)
  • VLAN segmentation for departments and services
  • Inter-VLAN routing and DHCP configuration
  • Firewall rules and access control lists
  • Redundancy and failover planning

What I Learned

This project deepened my understanding of how networks are actually built — not just configured. I learned to think about traffic flow, failure scenarios, and how security is layered rather than bolted on.

Tools Used

Cisco Packet Tracer Wireshark Network Security
