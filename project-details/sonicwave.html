SonicWave

A music streaming platform with playlists, favorites, and a clean player interface — built to explore audio in the browser.

Overview

SonicWave is a web-based music streaming platform designed for users who want a simple, focused listening experience. It organizes audio into tracks, albums, and playlists.

The platform includes user accounts, playlist creation, a favorites system, and a clean audio player with queue support.

Key Features

  • User registration and login
  • Track upload and streaming
  • Playlist creation and management
  • Favorites and recently played
  • Search by title, artist, or album

Technical Details

Built with HTML, CSS, PHP, and JavaScript, with MySQL storing users, tracks, playlists, and play history. Audio files are served through PHP with proper MIME handling.

The frontend player uses the HTML5 audio API, with JavaScript managing queues and playlist interactions.

Tech Stack

HTML CSS PHP JavaScript MySQL
