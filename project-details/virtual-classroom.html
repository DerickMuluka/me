Virtual Classroom

An online learning environment where teachers post lessons, share resources, and students access everything in one place.

Overview

Virtual Classroom is a web application that gives teachers and students a shared space for lessons, announcements, assignments, and learning materials. It was built to make remote learning simpler and more organized.

Teachers create classes, upload materials, and post assignments. Students enroll in classes, download resources, and track what they've completed.

Key Features

  • Teacher and student account roles
  • Class creation with enrollment codes
  • Lesson and resource uploads
  • Assignment posting and submission tracking
  • Simple class discussion board

Technical Details

The system uses HTML and CSS for the interface, PHP for server-side logic, JavaScript for interactive features, and MySQL for storage. File uploads are handled through PHP with proper validation.

Session-based authentication separates teacher and student views. The database stores classes, enrollments, lessons, assignments, and submissions.
