Asset Management System

A system for tracking, managing, and auditing organizational assets with request workflows and reporting.

Overview

The Asset Management System helps organizations keep track of their physical assets — equipment, furniture, electronics, and more. It replaces spreadsheets with a proper database solution.

The system supports the full asset lifecycle: acquisition, assignment, tracking, and disposal, with role-based access for administrators and staff.

Key Features

  • Asset catalog with categories and conditions
  • Request and approval workflow for asset issuance
  • Return tracking with condition assessment
  • Guest portal for browsing available assets
  • Reporting dashboard with asset value analytics

Technical Details

Built with HTML, CSS, PHP, JavaScript, and MySQL. The database schema is designed around the asset lifecycle, with tables for assets, categories, departments, requests, and users.

PHP handles all server-side logic including authentication, request processing, and report generation. JavaScript manages interactive forms and dynamic filtering.
