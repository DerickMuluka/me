Web App 2024 Campus Project

Voting Management System

A secure online voting platform with voter verification, one-vote enforcement, and real-time results.

Overview

The Voting Management System was built to modernize student elections. It replaces paper ballots with a digital process that is transparent, auditable, and easier to run.

The system handles voter registration, eligibility checks, secure ballot casting, and live result reporting.

Key Features

  • Voter registration and verification
  • One-vote-per-user enforcement
  • Secure ballot submission
  • Live results dashboard
  • Admin panel for election management

Technical Details

Built with HTML, CSS, PHP, JavaScript, and MySQL. Security was the main focus — hashed passwords, session protection, and prepared statements to prevent SQL injection.

Results are calculated from the database and displayed through a live dashboard using Chart.js for visualization.

Tech Stack

HTML CSS PHP JavaScript MySQL
