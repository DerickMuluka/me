EduSphere

A learning platform that gives students personalized, project-based learning paths with progress tracking and simple analytics.

Overview

EduSphere is a web-based learning platform designed for students who learn best by doing. Instead of static courses, it presents structured projects that students complete step by step.

The platform includes student accounts, project catalogs, progress tracking, and a simple dashboard that shows what each student is working on.

Key Features

  • Student registration and login system
  • Project catalog organized by difficulty and topic
  • Progress tracking for each enrolled project
  • Student dashboard with learning activity
  • Admin panel for managing projects and students

Technical Details

Built with HTML, CSS, PHP, and JavaScript on the frontend and server side, with MySQL as the database. The backend handles authentication, project management, and progress tracking through clean PHP scripts.

The database stores users, projects, enrollments, and progress records. JavaScript handles form validation and interactive elements on the dashboard.
